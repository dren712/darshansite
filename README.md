## Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm

### Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

### Production Build

```bash
# Build optimized static production bundle
npm run build

# Start production server
npm run start
```
